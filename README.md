 5-DOF 3D-Printed Robotic Arm (6-Axis Control)

> **End-to-end design, 3D printing, and C++ programming of a functional 5-DOF robotic arm using an Arduino Mega 2560.**

📄 **[Click here to view/download the full Engineering Portfolio Presentation (PDF)](ROBOTIC-ARM-PROJECT.pdf)**

 Overview
This repository contains the source code, 3D models, and media for a custom-built mechatronic system. For a detailed breakdown of the engineering process, thermal deformation solutions, custom power management, and deadband signal filtering, please refer to the comprehensive PDF presentation linked above.

 📂 Repository Structure
*   `/src` - Arduino C++ source code (`.ino`) for kinematics and joystick mapping.
*   `/cad` - `.stl` files and 3D models ready for printing.
*   `/media` - Demonstration video
*   `ROBOTIC-ARM-PROJECT.pdf` - Detailed project documentation and technical challenges solved.
